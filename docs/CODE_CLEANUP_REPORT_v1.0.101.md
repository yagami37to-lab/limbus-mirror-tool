# CODE CLEANUP REPORT v1.0.101

## 目的

URLパラメーターから投稿エディターを起動する処理を `app.js` から分離する。

## 今回の分割

`js/post-editor-launch-controller.js` へ以下を移動した。

- `draft` パラメーターからブラウザ下書きを開く処理
- `edit` パラメーターから既存投稿を取得する処理
- ログインユーザー本人の投稿であることの確認
- 読込失敗時と編集開始時の通知

## 結果

- 下書きから開く経路を優先する現在の動作を維持
- 他ユーザーの投稿を編集対象として取得しない条件を維持
- 投稿の復元処理とエディター起動処理の責務を分離

## 次の候補

第19段階では、投稿画面を閉じる確認・下書き保存・入力破棄の処理を専用コントローラーへ分離する。
