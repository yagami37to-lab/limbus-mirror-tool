# v1.0.53 通報・管理機能 Supabase設定

このバージョンでは、サイト側の更新だけでは通報・BAN機能は有効になりません。

## 実行するファイル

`database/migrations/supabase-v1.0.53-moderation-migration.sql`

## 操作

1. Supabase Dashboardで対象プロジェクトを開く。
2. 左側の「SQL Editor」を開く。
3. 「New query」を押す。
4. 上記SQLファイルの内容をすべて貼り付ける。
5. 「Run」を1回押す。
6. エラーが出なければ完了。
7. その後にv1.0.53のサイトZIPをCloudflare Pagesへ反映する。

## 追加される機能

- 表示名の重複防止（前後空白・大文字小文字を無視）
- 投稿詳細からの通報
- 管理者専用の通報管理画面
- 通報投稿の非表示 / 再表示 / 削除
- サイト内BAN / BAN解除
- BAN中ユーザーの投稿・編集・いいね・ブックマーク等の書き込み制限

## 補足

BANはこのサイト内の操作を停止する仕組みです。Supabase Authそのものへのログイン停止は行いません。秘密鍵をブラウザへ置かずに運用できるよう、サイト上の書き込み権限をRLSで停止します。
