# CODE CLEANUP REPORT v1.0.111

## 第26段階: テーマパック名の互換処理

### 目的

旧投稿や下書きに残るテーマパック名の表記揺れを補正する処理を共通化する。

### 今回の分割

`js/theme-pack-names.js` へ以下を移動した。

- 現行テーマパック名の一覧生成
- 全角・半角と区切り記号を除いた比較キー生成
- 記号差だけの旧表記を現行名へ変換
- 編集距離による軽微な誤記の補正
- 複数候補が同距離の場合に誤変換しない制御
- テーマパック配列の一括正規化

### 結果

- 投稿編集画面と公開投稿読込の重複ロジックを解消
- 既存投稿・ブラウザ下書きとの互換性を維持
- 共通ユーティリティを利用する全ページで読込順を明示

### 次の段階

第27段階では、テーマ切替・ダイアログ・通知・モバイルナビゲーションなどの共通UI処理を整理する。
