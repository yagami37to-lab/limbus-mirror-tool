# CODE CLEANUP REPORT v1.0.102

## 目的

投稿画面を閉じる際の確認と終了処理を `app.js` から分離する。

## 今回の分割

`js/post-close-controller.js` へ以下を移動した。

- 閉じる確認ダイアログの表示
- 編集を続ける操作
- 下書きを保存して閉じる操作
- 保存せず入力を破棄する操作
- Escキーによるキャンセルとスクロールロック解除

## 結果

- 投稿エディターの終了経路を一つのコントローラーへ集約
- 下書き保存に失敗した場合は画面を閉じない現在の動作を維持
- 保存・破棄後のエディター初期化処理を維持

## 次の候補
