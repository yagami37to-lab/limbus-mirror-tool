# CODE CLEANUP REPORT v1.0.112

## 第27段階: 共通UI処理

### 目的

サイト全体の基本UI制御を `app.js` から分離する。

### 今回の分割

`js/site-ui-controller.js` へ以下を移動した。

- ライト・ダークモードの切替と設定保存
- テーマ切替ボタンのアクセシビリティ表示
- ダイアログ表示中の背景スクロール固定
- 複数ダイアログの開閉数管理
- PC・iOS Safari向けのスクロール位置復元
- トースト通知の表示時間管理
- スマホ用ナビゲーションの開閉

### 結果

- 共通UIと投稿エディター処理の責務を分離
- 既存コントローラーは同じダイアログ・通知APIを継続利用
- ページ復帰時のスクロールロック復旧を維持

### 次の段階

第28段階では、参照・構文・重複・不要コード・データ互換性を全体監査し、整理作業を完了する。
