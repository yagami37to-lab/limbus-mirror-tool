# CODE CLEANUP REPORT v1.0.107

## 第22段階: 投稿カテゴリ選択

### 目的

投稿カテゴリ選択画面の描画と操作を `app.js` から分離する。

### 今回の分割

`js/post-category-controller.js` へ以下を移動した。

- 利用可能・実装予定カテゴリの候補描画
- 選択中カテゴリの表示と投稿開始ボタンの有効化
- ログイン状態を確認してカテゴリ画面を開く処理
- カテゴリ画面から下書き一覧を開く処理
- 選択カテゴリで新規投稿を開始する処理
- 投稿画面と確認画面のカテゴリ表示同期

### 結果

- 未実装カテゴリを選べない現在の制限を維持
- 新規投稿開始前のエディター初期化を維持
- カテゴリ選択と投稿エディター本体の責務を分離

### 次の段階

第23段階では、攻略タグ・所属タグ・自動キーワードの集計と描画処理を専用コントローラーへ分離する。
