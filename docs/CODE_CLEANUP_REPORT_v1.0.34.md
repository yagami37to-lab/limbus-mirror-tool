# CODE CLEANUP REPORT v1.0.34

## 目的
現在稼働しているコードの挙動を変えず、`styles.css` と `app.js` の内部を安全な範囲で整理する。

## styles.css
- 3か所に分散していた `:root` のCSSカスタムプロパティを先頭の1か所へ集約。
- 射影戦闘カテゴリの画像見切れ対策として末尾に残っていた `!important` ホットフィックスを、既存のカテゴリ画像ルールへ統合。最終的な `overflow: visible` / `padding: 4px` / `object-fit: contain` の挙動は維持。
- `v0.x.x` / `v1.x.x` の履歴番号を含むコメントから番号だけを外し、機能の説明を残した。
- 動的クラスやレスポンシブ上書きの可能性がある重複セレクタは、見た目を壊す危険があるため今回は削除していない。

## app.js
- `closeIdentitySelect()` は app.js 内で定義以外の参照がなく、HTML / その他JSを含むプロジェクト全体でも参照がないことを確認して削除。
- `selectedIdentities` / `party` の復元仕様コメントを、特定バージョン依存ではなく現在のデータ仕様として読める記述へ変更。
- 投稿・検索・おすすめ・認証などのロジック自体は変更していない。

## 今回あえて行わなかったこと
- `styles.css` の大規模ファイル分割。CSSの読み込み順によるカスケード変更を避けるため。
- `app.js` のES Modules化。HTML全体の読み込み方式変更を伴うため。
- 使用頻度だけを根拠にしたCSSセレクタ削除。JavaScriptで動的に付与されるクラスを誤削除しないため。

## 推奨する次段階
次回さらに整理する場合は、実画面テストを併用しながら `styles.css` を「共通 / 投稿エディター / 閲覧詳細 / アカウント / レスポンシブ補正」の順に段階分割すると安全。
