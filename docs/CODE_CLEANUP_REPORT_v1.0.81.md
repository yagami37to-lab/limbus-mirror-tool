# CODE CLEANUP REPORT v1.0.81

## 目的

肥大化している `app.js` のうち、投稿検索に関係する状態・DOM参照・表示処理・イベント接続を独立させる。

## 今回の分割

以下を `js/search-controller.js` へ移動した。

- 人格検索モーダル
- 攻略カテゴリ、人格、キーワード、攻略タイプ、攻略タグ、難易度、所属、フリーワード、日付の検索条件
- 検索条件チップの表示と解除
- 検索パネルの開閉
- おすすめ順、更新順、新着順、閲覧順、いいね順の並び替え
- 1ページ6件のページ切り替え
- 閲覧カテゴリタブ
- 投稿読み込み・いいね更新後の再検索

## 接続方法

`app.js` は、人格名一覧、カテゴリ定義、検索候補、共通モーダル操作、トースト表示だけを検索コントローラーへ渡す。検索側の選択状態やページ番号は専用ファイル内に閉じ込めた。

## 結果

- `app.js`: 約107KBから約93KBへ縮小
- 検索処理: `js/search-controller.js` 約17KBへ独立
- 投稿エディター、下書き、E.G.O、テーマパック、Supabase保存処理は変更なし

## 次の候補

第3段階では、ローカル下書きの保存・復元・一覧表示・削除処理を専用ファイルへ分離する。
