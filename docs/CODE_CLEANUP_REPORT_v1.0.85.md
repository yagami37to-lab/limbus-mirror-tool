# CODE CLEANUP REPORT v1.0.85

## 目的

投稿エディター内で独立性の高いE.G.O選択処理を分離し、人格選択の整理前に `app.js` の責務を減らす。

## 今回の分割

以下を `js/ego-controller.js` へ移動した。

- 編成済み囚人のE.G.O一覧
- ランク別E.G.Oの選択と解除
- 自由枠に対するE.G.O指定の有効化と解除
- 囚人単位・全体の選択解除
- 選択件数とフッター操作状態の更新
- E.G.O一覧と個別選択画面の切り替え

## 接続方法

`app.js` は投稿状態、人格・E.G.Oデータ、編成順、共通表示処理をコントローラーへ渡す。ステップ移動、投稿復元、投稿種別変更からは、一覧描画・画面を閉じる・操作状態更新の3つだけを呼び出す。

## 結果

- `app.js`: 約82KBから約75KBへ縮小
- E.G.O選択: `js/ego-controller.js` 約8KBへ独立
