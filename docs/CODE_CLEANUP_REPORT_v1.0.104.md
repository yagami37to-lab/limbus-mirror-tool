# CODE CLEANUP REPORT v1.0.104

## 目的

投稿の基本情報に関する入力イベントと表示同期処理を `app.js` から分離する。

## 今回の分割

`js/post-basics-controller.js` へ以下を移動した。

- 投稿タイトルとタイトルプレビューの同期
- 日本語入力の変換中・確定後の同期
- 攻略タイプの選択とプレビュー更新
- 難易度の選択とバッジ更新
- 難易度変更時のテーマパック解除確認
- ソロ攻略切替時の編成順とE.G.Oの整理

## 結果

- 投稿基本情報の入力処理を一つのコントローラーへ集約
- 日本語入力時のタイトル反映経路を維持
- 攻略タイプ・難易度変更時の既存仕様を維持
