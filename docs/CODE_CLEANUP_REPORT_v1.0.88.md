# CODE CLEANUP REPORT v1.0.88

## 目的

人格カードの表示と投稿状態の変更を切り離し、人格選択機能を安全に保守できる構造へ近づける。

## 今回の分割

`js/identity-selection-controller.js` へ以下を移動した。

- 使用人格の設定
- 自由枠の設定と関連E.G.Oの解除
- 代用人格の追加・解除
- 囚人単位・全体の人格解除
- 未設定枠の一括自由枠化

## 結果

- 人格カード描画と状態変更の責務を分離
- 投稿・下書きデータ形式は変更なし
- 次段階で囚人一覧と人格カード描画を移動できる接続構造を作成

## 次の候補

第8段階では、囚人一覧・人格カード・代用人格表示の描画処理を専用コントローラーへ統合する。
