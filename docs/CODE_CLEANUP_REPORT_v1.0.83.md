# CODE CLEANUP REPORT v1.0.83

## 目的

`app.js` に残っていた、ブラウザ内のローカル下書き管理を独立させる。

## 今回の分割

以下を `js/draft-controller.js` へ移動した。

- 最大5件の下書き保存
- 下書き一覧の表示
- 下書きの読み込み、上書き、削除
- URLから指定された下書きの再開
- 公開完了後の下書き削除
- 下書き管理画面のイベント接続

## 接続方法

`app.js` は投稿画面の状態をオブジェクトへ変換する処理と、その状態を画面へ復元する処理だけを担当する。下書きコントローラーには、この2つの処理と共通モーダル・トースト操作を渡して接続した。

## 結果

- `app.js`: 約93KBから約87KBへ縮小
- 下書き管理: `js/draft-controller.js` 約5KBへ独立
- 既存の保存キーと最大5件の制限は変更なし
- 「下書き保存して閉じる」の完了判定と、閉じる確認画面のスクロール解除も修正
