# CODE CLEANUP REPORT v1.0.98

## 今回の分割

`js/post-restore-controller.js` へ以下を移動した。

- 投稿基本情報と入力欄
- 人格と代用人格
- 編成順
- E.G.O
- テーマパック
- 攻略タグと所属タグ
- 下書きの編集中ステップ
- 旧投稿形式の互換読込

- 下書きと既存投稿が同じ画面再描画経路を利用
- 復元時の状態初期化漏れを防ぎやすい構造へ整理
