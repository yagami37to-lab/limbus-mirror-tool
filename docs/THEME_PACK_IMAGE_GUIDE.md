# テーマパック画像の提出・配置ガイド

画像名と配置先は [`theme-pack-image-list.csv`](theme-pack-image-list.csv) を正本とします。現行の `data/packs.json` に登録されている名称を重複除去し、全119件を一覧化しています。

## 提出方法

1. CSVで対象のテーマパック名を検索します。
2. `filename` 列の3桁連番へ画像名を変更します（例: 「忘れ去られた者たち」は `001.png`）。
3. 画像をパック単位、または複数枚をまとめたフォルダーで提出します。

配置先はすべて `assets/theme-packs/` です。推奨形式はPNGです。

## 画像仕様

- 元画像は切り抜かず、縦長のまま提出してください。
- 最初の実画像を確認してから、投稿画面のカードへ共通の `aspect-ratio` を設定します。
- 一覧表示では画像全体を確認できる `object-fit: contain` を基本候補とし、余白・名称表示・選択状態は実画像に合わせて調整します。
- 投稿確認画面と投稿詳細画面では、選択画面より小さいサムネイル表示を別途調整します。

## 現在の適用画像

- ノーマルの全51種（`001.png`〜`051.png`）
- 元画像はおおむね縦横比 約1.8〜2.0:1です。
- 投稿画面の選択カードでは、画像ごとの寸法差を吸収しつつ全体を切り抜かず表示します。
