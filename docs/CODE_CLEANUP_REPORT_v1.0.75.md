# CODE CLEANUP REPORT v1.0.75

## 目的

肥大化しているルートの `app.js` を、動作を変えずに機能単位で段階的に整理する。

## 今回の分割

管理者おすすめの選定、投稿カード複製、ブックマーク状態同期、カルーセル制御、投稿読み込み後の再描画を `js/featured-recommendations.js` へ移動した。

この処理は投稿検索や投稿エディターの内部状態を参照しておらず、DOM上の投稿カードと `limbus-posts-loaded` イベントだけで完結しているため、第一段階の分割対象として選定した。

## 維持した動作

- 最近の投稿、今日の高評価、最高いいね、最高閲覧の選定条件
- おすすめカード内の人格表示上限
- いいねとブックマークの状態同期
- 自動送り、前後操作、ドット操作、一時停止
- モーション軽減設定への対応
- Supabaseから投稿を読み込んだ後の再描画

## 結果

- `app.js`: 約117KBから約107KBへ縮小
- おすすめ表示: `js/featured-recommendations.js` 約10KBへ独立
- 投稿検索、投稿エディター、下書き、Supabase保存処理は変更なし

## 次の候補

次回以降は、依存関係を確認しながら検索UI、投稿下書き管理、投稿エディター補助処理を個別に検討する。一度に複数領域を移動せず、各段階でPC・スマホとライト・ダークを確認する。
