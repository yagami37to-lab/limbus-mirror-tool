# CODE CLEANUP REPORT v1.0.110

## 第25段階: 入力検証と画面誘導

### 目的

投稿ステップの入力検証結果を画面へ反映する処理を `app.js` から分離する。

### 今回の分割

`js/post-validation-flow-controller.js` へ以下を移動した。

- 必須入力ステップの検証結果表示
- タイトル・難易度・攻略タイプへの画面誘導
- 未設定人格、編成順、一言紹介への画面誘導
- 公開前に全必須ステップを検証する処理
- ステップを飛ばす際に途中の未入力を検出する処理
- ポップアップとトースト通知の振り分け

### 結果

- 入力条件の判定と画面誘導の責務を分離
- 最初の不備ステップへ戻す現在の動作を維持
- エラー対象へのフォーカスとスクロールを維持

### 次の段階

第26段階では、テーマパック名の旧表記互換・正規化処理を専用ユーティリティへ分離する。
