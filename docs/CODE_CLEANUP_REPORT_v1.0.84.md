# CODE CLEANUP REPORT v1.0.84

## 目的

投稿エディター内の選択機能を段階的に整理し、各機能の変更範囲を小さくする。

## 今回の分割

以下を `js/theme-pack-controller.js` へ移動した。

- 難易度に応じた階層一覧の表示
- 階層別テーマパック候補の表示と検索
- 選択、変更、解除
- 同じテーマパックの重複選択防止
- HARD 6F～15Fの自由枠
- 選択画面の開閉とイベント接続

## 接続方法

`app.js` は投稿状態、テーマパックデータ、共通スクロール・トースト処理をコントローラーへ渡す。難易度変更、投稿内容の復元、確認画面の描画からは、小さな公開メソッドだけを呼び出す。

## 結果

- `app.js`: 約87KBから約82KBへ縮小
- テーマパック選択: `js/theme-pack-controller.js` 約5KBへ独立
- 下書き操作ボタンのダークモード配色も修正

## 次の候補
