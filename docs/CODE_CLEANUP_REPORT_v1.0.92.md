# CODE CLEANUP REPORT v1.0.92

## 目的

公開投稿とブラウザ下書きで利用する投稿データの生成責務を `app.js` から分離する。

## 今回の分割

`js/post-payload-controller.js` へ以下を移動した。

- 使用人格と代用人格
- 編成順
- E.G.O
- テーマパック
- 自動キーワード
- 攻略タグと所属タグ
- タイトル、紹介文、攻略説明

## 結果

- Supabase保存とブラウザ下書きが同じデータ生成経路を利用
- 既存の投稿・下書きデータ形式は変更なし
- 保存項目を追加・修正する場所を一つに集約

第12段階では、投稿確認画面のカード・タグ・テーマパック表示を専用ビューへ分離する。
