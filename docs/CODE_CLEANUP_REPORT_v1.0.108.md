# CODE CLEANUP REPORT v1.0.108

## 第23段階: タグと自動キーワード

### 目的

攻略タグ・所属タグ・自動キーワードの集計と描画を `app.js` から分離する。

### 今回の分割

`js/post-tags-controller.js` へ以下を移動した。

- 攻略タグ5件、所属タグ3件の選択上限
- 出撃枠1〜7からの通常キーワード集計
- 全編成枠からの弾丸キーワード集計
- 弾丸タグの任意選択
- ソロ攻略タグの自動付与
- 投稿画面のタグ候補と件数表示

### 結果

- タグ選択と投稿データ用キーワード生成が同じ集計経路を利用
- 自由枠を自動キーワード集計から除外する仕様を維持
- 現在の付与条件と選択上限を維持
